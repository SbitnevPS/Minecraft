# Mechanical Universe

Minecraft Forge 1.20.1 source prototype (Java 17). This is **not** a compiled .jar. Not tested in Minecraft.

Includes a registry of 60 decorative engineering-part blocks, an infinite lava bucket source, an infinite water bucket source and an eight-portion water/lava bucket. Rotation, functioning machines, fluid piping and assembly are **not yet implemented**.

Start with a Forge 1.20.1 MDK; use Java 17 and run `gradlew build`. Asset models, recipes and lang files are still to be added to this GitHub copy.
